# Movie Library — Flutter Assignment

## Included
- Movie data model and 8 sample movies
- Local poster-style images in `assets/posters/`
- Search by title or genre (case-insensitive), without `TextEditingController`
- Switch between `ListView.builder` and `GridView.builder`
- Rating badge colors and responsive grid columns
- Empty-state message and result count

## Run
1. Install Flutter and create/ open this folder in VS Code.
2. In the project root, run:
   ```bash
   flutter pub get
   flutter run
   ```
3. Take screenshots of list view and grid view with a search applied.
4. Create a GitHub repository and push the project files.

The poster files are original illustrative placeholders, not official movie posters. You can replace them with your own images while keeping the filenames or updating `movie.dart`.
Do not upload the `build/` directory.
